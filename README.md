# Археолог знаний

Дорожная карта голосового ИИ-интервьюера, который в разговоре с экспертом выявляет скрытые знания: правила, критерии, «красные флаги» и справочники, которые человек держит в голове и называет опытом.

**Сайт:** https://xxdioxx.github.io/arheolog-znaniy/

Основа — книга Дмитрия Гуреева «Цифровое мышление в бизнесе» (2026): метод скрытых артефактов, четыре типа работы, ассистент-критик, схема «Методолог + ИИ-агент».
